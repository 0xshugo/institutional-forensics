# Module: JP Address Forensics

このモジュールは `institutional-forensics` を、日本の住所・地番・住居表示の不整合調査に適用するためのドメイン拡張である。

Version: 0.1.0

## Domain layers

住所文字列を一つの値として扱わない。

最低限、以下を分離する。

1. 町名・丁目
2. 街区符号
3. 基礎番号
4. 住居番号
5. 土地の地番
6. 棟番号
7. 各戸番号 / 部屋番号
8. 施設が便宜上使用する所在地表記

例:

```text
2-1-2
```

は文脈により、

```text
2丁目1番2号
2丁目1番地2
2丁目1番2号棟
```

など異なる概念を表し得る。

探索用データを最終根拠と混同しない。

## Address-specific hypotheses

```text
H1 地番住所と住居表示の混同
H2 一方が誤記 / 便宜表記
H3 基礎番号と正式住居番号の差
H4 団地 / 中高層建物の棟番号特例
H5 旧住所と新住所の混在
H6 制度上の住居番号重複
H7 各戸番号省略による見かけの重複
H8 自治体独自ルール
H9 過去の付番を維持する経過的運用
```

## Critical caution

国土地理院の住居表示住所データに示される基礎番号は、個別建物の正式住所一覧そのものではない。

したがって:

```text
基礎番号 != 常に正式住居番号
```

不一致を見つけても即「住所誤り」としない。

## Address workflow

1. 対象建物を別Entityとして確定
2. 位置・接道・同一街区か確認
3. 住居表示実施地区か確認
4. 街区符号・基礎番号確認
5. 地番確認
6. 問題住所の公式使用実績確認
7. 住居表示法・実施基準・自治体規程確認
8. 団地 / 中高層 / 棟番号 / 各戸番号 / 枝番号の特例確認
9. 建設・移転・住居表示開始・制度改正の時系列復元
10. 必要なら住居表示台帳・担当課照会へ進む
