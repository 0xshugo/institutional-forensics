# Case Study: 「家電には法定保証1年がある」という通説（AppleCare / 日本・EU）

Status: corrected verified case / historical anchor resolved in v0.1.6 (some AppleCare+ revision history out of scope)  
Skill: `institutional-forensics`  
Primary mechanisms: Premise / Document Function / Claim Dimensions / Scope / Timeline / Falsification

## Premise status

**Refuted as stated, but the earlier refutation was itself overbroad.**

検証対象の通説:

```text
家電には「法定保証1年」がある
```

日本法には、家電一般について「購入日から1年間、メーカーが無償保証しなければならない」という一律の法定メーカー保証制度は確認できない。

ただし、以前の本ケースはここからさらに

```text
「売買には1年という期間規定は存在しない」
```

と進めており、これは誤りだった。

現行民法566条は、**種類または品質の契約不適合について、買主が不適合を知った時から1年以内に売主へ通知しない場合、原則として一定の救済を行使できない**と定めている。

したがって、正しい分解は次のとおり。

```text
Appleの「購入日から1年」
= 任意のメーカー保証（commercial warranty）

民法566条の「知った時から1年」
= 売買の契約不適合に関する通知期間

民法166条の「5年 / 10年」
= 一般的な消滅時効のルール
```

これらは同じ「1年」「保証」という言葉で近接して見えるが、法的機能が異なる。

Confidence: **Confirmed for this structural distinction.**

---

## Claim Dimensions

「保証」という語を一つの値として扱わない。

```text
statutory remedy      法律に基づく救済
notice period         権利行使の前提となる通知期間
limitation period     消滅時効
commercial warranty   事業者が任意で付与する保証
service plan          AppleCare+等の追加契約
incident limit        事故サービスの回数制限
coverage scope        事故・盗難・紛失等の対象範囲
```

特に、

```text
通知期間 != 消滅時効 != メーカー保証期間
```

である。

## Governing evidence

### 日本 — 民法

#### 契約不適合に対する救済

民法562条は、種類・品質・数量について契約内容に適合しない目的物が引き渡された場合の追完請求を定める。563条は代金減額、564条は損害賠償・解除との関係を定める。

- issuer: 日本国
- function: normative
- object_level: 売買契約
- valid_at: 2026-09-17
- source: https://laws.e-gov.go.jp/law/129AC0000000089

#### 売買にも「1年」の通知期間がある

民法566条は、種類・品質の契約不適合について、買主が不適合を知った時から1年以内に売主へ通知しない場合、原則として追完、減額、損害賠償、解除を行使できないと定める。ただし、売主が引渡し時に不適合を知っていた、または重大な過失で知らなかった場合は例外となる。

したがって、旧版サンプルの

```text
「1年」の実在の所在は請負637条だけ
```

という記述は誤り。

#### 消滅時効は別レイヤー

民法166条は、債権について「権利を行使できることを知った時から5年」または「権利を行使できる時から10年」という一般的な消滅時効を定める。

これをメーカー保証期間や566条の通知期間と同一視しない。

#### 旧法の「1年」— 通説の歴史的アンカー（v0.1.6 追加検証）

2017年改正前の民法には、**物の隠れた瑕疵について「買主が事実を知った時から1年」の権利行使期間**が明文化されていた。

```text
（売主の瑕疵担保責任）
第五百七十条
　売買の目的物に隠れた瑕疵があったときは、第五百六十六条の規定を準用する。
ただし、強制競売の場合は、この限りでない。

（地上権等がある場合等における売主の担保責任）
第五百六十六条
 ３　前二項の場合において、契約の解除又は損害賠償の請求は、
買主が事実を知った時から一年以内にしなければならない。
```

つまり「1年」という数字はでたらめではなく、**改正前法の正確な引用**だった。

- 旧570条（瑕疵担保責任）→ 旧566条3項を準用 → **事実を知った時から1年**
- 旧564条（権利の一部が他人に属する場合）にも独立の1年行使期間があった
- 旧法の売買・瑕疵条文に**「六箇月」の期間規定は存在しない**（本ケースの旧版が仮説として置いていた「6か月」も、旧法全文確認により棄却。通説の二次的誤りだった）
- 2017年改正（平成29年法律第44号）により、この「1年行使期間」は新566条の**「1年通知期間」**へ転換され、救済請求権自体は166条の一般時効に従う構造に変わった

- valid_at: 改正前条文は2017年改正前法（最終改正: 平成23年法律第74号）時点
- source: 法令データ提供システム（旧 e-Gov）本文クロール（2013-12-21取得、GitHub アーカイブ） https://github.com/riywo/law.e-gov.go.jp — evidence class E（公式コンテンツの第三者ミラー）
- cross-check: 現行条文は e-Gov 法令 API v2（law_id 129AC0000000089、改正 129AC0000000089_20260624_508AC0000000045）で確認済み

### Apple — 1年限定保証

Appleは日本向け保証文書で、Apple製品1年限定保証を**任意のメーカー保証**として位置づけ、消費者法に基づく権利とは別に提供されると説明している。

また、通常使用時の材質・製造上の瑕疵について、最初の販売店での購入日から1年間を保証期間としている。

- issuer: Apple
- function: normative / explanatory
- object_level: Apple製品の商用保証
- valid_at: 2026-09-17
- source: https://www.apple.com/jp/legal/warranty/products/accessory-warranty-japanese.html
- related: https://www.apple.com/jp/legal/warranty/products/warranty-japanese.html

ここから確認できるのは、Appleの1年保証が**法定権利に追加される商用保証**だということ。

### EU — 2年という別法域の数字

Directive (EU) 2019/771 Article 10(1) は、売主の適合性責任について原則2年の期間を置く。

これはEUの制度であり、日本法の「法定保証1年」を裏づけるものではない。

- issuer: European Union
- function: normative
- object_level: EU consumer sales
- valid_at: directive framework
- source: https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32019L0771

## AppleCare+ の別レイヤー

AppleCare+は、Appleの1年限定保証そのものでも、民法上の契約不適合責任そのものでもない追加サービス契約。

過去のAppleCare+約款を比較すると、事故損傷のサービスイベント回数は改定されている。

```text
2022年版: 12か月につき2回
2025年版: 有効期間中のサービスイベントを無制限
```

ただし「無制限」は、サービス料、補償対象、盗難・紛失の有無、契約有効期間まで無制限という意味ではない。

これもClaim Dimensionsの問題である。

## What the earlier version got wrong

旧版は「法定保証1年」という通説を崩す過程で、次の新しい否定命題を十分に反証しなかった。

```text
物の売買には対応する「1年」規定はない
```

民法566条を確認すれば、この否定命題は棄却できる。

### Failure mode

```text
誤った通説を否定する
↓
もっともらしい代替説明を作る
↓
代替説明を構成する「存在しない / 一度もない / only」を再検証しない
```

制度フォレンジックでは、**最終結論だけでなく、その結論を支える決定的な否定命題も反証対象にする必要がある。**

なお、旧版が「本当は6か月では?」と置いていた仮説も、v0.1.6で旧法全文（法令データ提供システム2013年クロール）を確認し棄却した。**通説の「1年」は旧566条3項＋旧570条の正確な記憶であり、誤りは「現行でも行使期間が1年」という陳腐化と、Appleの契約上の1年保証との混同**にある。否定命題の再検証は、仮説側にも適用される。

## Current conclusion

### Confirmed

- 日本に「家電一般を購入日から1年間メーカーが無償保証する」という単純な一律法定メーカー保証制度がある、とは確認できない。
- Appleの1年限定保証は、Apple自身が任意のメーカー保証として位置づけている。
- 日本の売買法には、民法566条として「不適合を知った時から1年以内」の通知期間が存在する。
- 民法166条の消滅時効と566条の通知期間は別制度。
- 2017年改正前の旧法では、隠れた瑕疵の解除・損害賠償は「事実を知った時から1年」の行使期間に服した（旧570条→旧566条3項）。通説の「1年」はここに歴史的アンカーを持つ。
- 旧法の売買・瑕疵条文に「6か月」規定は存在しない。
- EUの2年ルールは別法域。

### Unresolved / out of scope

- 個別の消費者取引で566条・166条その他の規定がどう組み合わさるかは、具体的事実関係により得るため、本ケースでは個別法律相談として断定しない。
- AppleCare+のすべての改訂時点を網羅した変更履歴は未作成。

### Confidence

**Confirmed for the layer separation; individual legal outcomes remain case-specific.**

## Falsification

この結論を覆し得るもの:

1. 日本法に、対象家電について購入日を起点とする一律1年のメーカー保証義務を直接定める現行条文が見つかる。
2. Appleの1年限定保証が、日本の法定保証義務そのものとして位置づけられている一次資料が見つかる。
3. 本文で「存在しない」とした期間規定について、隣接条文・特別法に反例が見つかる。

このケースでは3が実際に起きたため、旧版を修正した。
