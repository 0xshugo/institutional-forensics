# Case Study: 高松市楠上町2-1-2の重複

Status: demonstration / not fully adjudicated  
Skill: `institutional-forensics` + `modules/jp-address.md`

## Anomaly

高松市楠上町二丁目付近にある別々の建物について、公開資料上いずれも `楠上町2-1-2` という住所表記が確認される。

見かけ上は「異なる建物に同一の住居表示が割り当てられている」ように見える。

## Entities

- 高松高等予備校 楠上寮
- 楠上第二住宅 2号棟

## Initial hypotheses

```text
H1 地番と住居表示の混同
H2 一方の単純誤記
H3 基礎番号と住居番号の差
H4 中高層建物・団地の棟番号特例
H5 新旧住所の混在
H6 制度上の番号重複
H7 各戸番号省略による見かけの重複
```

## Evidence chain to reproduce

### 1. Position

地理院地図等で両建物が別位置にあり、同じ楠上町二丁目1番街区付近にあることを確認する。

- https://maps.gsi.go.jp/#18/34.329782/134.054536/

### 2. Basic numbers

国土地理院の住居表示住所データで、当該街区の基礎番号配置を確認する。

- https://saigai.gsi.go.jp/jusho/view/data/37201/37201_288.html

ここでは、楠上寮付近と楠上第二住宅2号棟付近の基礎番号が同じではないように見える。

ただし、基礎番号はそのまま全建物の正式住居番号一覧ではないため、この時点で誤記とは断定しない。

### 3. Parcel numbers

地番可視化資料等で敷地の地番を確認し、`1-2` が地番由来である可能性を評価する。

探索例:

- https://chiban.koaza.net/#18.85/34.3299721/134.0549178

民間可視化は探索用とし、必要なら公的地番資料で追認する。

### 4. Official usage

行政資料で楠上第二住宅の所在地として同住所表記が実際に用いられているか確認する。

例:

- 内閣官房サイト内「財務省所管の施設についてのデジタル化改修計画及び受信障害への対応計画」
- https://www.cas.go.jp/jp/seisaku/digitalbroadcast/actionplan/090331pdf/2zaimu.pdf

行政資料にも同じ表記があれば、単純な民間地図の誤記仮説は弱くなる。

### 5. Governing rule

「住居表示に関する法律」だけでなく、街区方式の実施基準にある団地・中高層建物の特例を確認する。

重要な検証点:

- 整然と棟番号が付けられた中高層建物について、棟番号を住居番号として扱える規定があるか
- 各戸番号をどのように組み合わせるか

### 6. Timeline

検証候補:

```text
1960年代: 高松市で住居表示実施
1980年代以降: 税務署移転後、官舎・宿舎が整備された可能性
2004年: 楠上寮建設とされる
2022年以降: 高松市で重複住居番号への枝番号制度
```

各年は必ず個別一次資料で再確認する。

## Working explanation

現時点で制度的に最も整合的な説明は、

1. 楠上第二住宅2号棟には、中高層建物・団地に関する住居表示上の特例により「2」という棟番号由来の住居番号が使われ、
2. 後に別の建物について一般的な基礎番号に基づく「2」が住居番号として成立し、
3. 結果として同一街区内に同じ `2-1-2` 表記が併存した

という可能性である。

ただし、**個別の付番決定記録を確認していない限り Confirmed ではない。**

Confidence: Highly likely / pending primary individual record

## What would confirm it

- 高松市の住居表示台帳
- 当時の住居番号設定記録
- 楠上第二住宅の建設・付番時資料
- 四国財務局等の国有財産台帳
- 高松市担当課への照会

## Why this case matters

この例のポイントは、「地図上の番号が違うのに同じ住所」という現象を単純な誤記として処理せず、

```text
一般則
→ 特例
→ 個別適用
→ 時系列
→ 現在の運用
```

へ分解することで説明候補を作れる点にある。

住所問題は `institutional-forensics` の最初のケーススタディとして扱う。
